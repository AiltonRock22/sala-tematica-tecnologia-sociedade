# 🌐 Sala Temática: Impacto da Tecnologia na Sociedade
> **Projeto Interdisciplinar de Ciências Humanas / Filosofia**  
> **Orientação:** Prof. Ailton Carlos

Este repositório contém a aplicação web interativa da **Sala Temática**, um projeto colaborativo desenvolvido pelas turmas do Ensino Médio. A mostra aborda de forma crítica e reflexiva os impactos, desafios e transformações da tecnologia na sociedade contemporânea.

---

<!-- STREAMING_CHUNK:Descrevendo a estrutura das turmas -->
## 📚 Organização e Trabalho das Turmas

O projeto é construído a muitas mãos, dividindo as responsabilidades de pesquisa, arte e tecnologia entre os anos:

* **1º Ano — Fundamentação Teórica e Banner:**
  * Realização de pesquisa teórica sob orientação docente.
  * Arte gráfica do **Banner Finalizado e Entregue** pela turma.
* **2º Ano — Embasamento Teórico e Design:**
  * Investigação e levantamento bibliográfico sobre o tema.
  * Finalização da arte gráfica do **Banner** para exibição.
* **3º Ano — Tecnologia, Robótica e Desenvolvimento Web:**
  * Criação e manutenção da **Plataforma Web (este site)**.
  * Desenvolvimento de protótipo de **Robótica com Arduino** para demonstração interativa durante a exposição.
* **Mural da Sala Temática (Espaço Físico):**
  * Curadoria de notícias de jornais/revistas impressas.
  * Oficina com os alunos para montagem de uma composição visual e artística nas paredes da sala.

## 🎥📂 Recursos Multimídia (Google Drive)

Os arquivos de vídeo e áudio gravados para apoiar os alunos monitores e os visitantes da sala temática estão hospedados no **Google Drive**.

### Como atualizar os links no projeto:
Para inserir os vídeos ou áudios do seu Google Drive no site:
1. No Google Drive, clique com o botão direito no arquivo de vídeo ou áudio.
2. Selecione **Compartilhar** > **Qualquer pessoa com o link pode ver**.
3. Copie o link (exemplo: `https://drive.google.com/file/d/1ABC123xyz.../view?usp=sharing`).
4. Na seção **Central Multimídia** do site, clique em **"Adicionar Novo Vídeo ou Áudio"** e cole o link do Drive. O sistema converterá automaticamente o link para exibição no player!

## 🛠️ Tecnologias Utilizadas

* **HTML5** & **JavaScript ES6+**
* **Tailwind CSS** (Design responsivo e estilização via CDN)
* **FontAwesome 6** (Iconografia temática)
* **Arduino (C/C++)** (Prototipagem física e robótica)
* **Google Drive API / Embeds** (Suporte a streaming de mídia)
